# Louvansky Benjamin's portfolio

A personal portfolio built with plain HTML, CSS, and JavaScript. The Home, About Me, Projects, and Skills pages
introduce my studies at NJIT, my work at American Electrical Technologies INC,
my practical skills, and my interests.
It includes responsive navigation, a dark mode toggle, and my LinkedIn profile.

## View locally

Double-click `index.html` to open the website in a browser. No installation or
build step is required.

## Deployment

The intended GitHub Pages address is https://louvansky.github.io/portfolio/.
Publication has not yet been verified. Projects include a disconnect relocation
and electrical panel work with a dedicated AC circuit, each with two photos. One more
project and a separate Contact page remain to be added. The Connect navigation
link currently points to the contact section on Home.

## Assets

Uses system fonts and no third-party libraries. Project photos were supplied by
Louvansky Benjamin and converted from HEIC to compressed JPEG for browser support.
Project descriptions reflect the owner’s account of the work; NEC references are
project context, not an independent compliance assessment.
